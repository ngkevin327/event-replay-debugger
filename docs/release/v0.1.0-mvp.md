# Release v0.1.0-mvp

**Date:** 2026-05-20  
**Tag:** `v0.1.0-mvp`  
**Status:** General availability (design partner program)

## Highlights

- End-to-end incident replay for Kafka-backed async services
- Operator web UI with virtualized timeline and workflow graph
- Staging environment on AWS EKS with repeatable Helm deploys
- Signed webhooks and shareable read-only incident links
